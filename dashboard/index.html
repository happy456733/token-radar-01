TOKEN RADAR

Every protocol that records no token, ranked by what its token would be worth.

How the radar scores

Implied value = TVL × the category’s comparable multiple × growth × tenure. The multiple is the median market-cap-per-TVL of the live-token protocols in the same category, taken from this snapshot — never a hardcoded list of names. Growth is the 7-day TVL change; tenure is how long the protocol has run with no token. Live-token protocols are set apart in the Live tokens view at their market value, never mixed into the ranking.

A protocol on this board records no token in DefiLlama’s data — that is not proof it has none, and the board never predicts whether or when a token is issued. Values are this radar’s own claim.
